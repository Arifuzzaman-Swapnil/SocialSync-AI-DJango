Connect Facebook Page

How to get credentials:
1. Go to Graph API Explorer
2. Select your app → Generate Access Token
3. Add permissions: pages_manage_posts, pages_read_engagement
4. Query: /me/accounts to get Page ID and Page Access Token
{% csrf_token %}
Your Facebook Page ID (numeric)
Long-lived Page Access Token from Graph API Explorer

4. Copy all 4 credentials below

Connect Instagram Business Account

How to get credentials:
1. Instagram account must be a Business account
2. Must be connected to a Facebook Page
3. Use same Facebook Page Access Token as above
4. Get Business Account ID from Graph API: /me?fields=instagram_business_account
{% csrf_token %}
Your Instagram Business Account ID (numeric)
Facebook Page Access Token (same as above)

Connect LinkedIn Account

How to get credentials:
1. Complete OAuth 2.0 flow to get Access Token
2. Get Person URN from /v2/userinfo API (the 'sub' field)
3. Token expires in 60 days - needs refresh
{% csrf_token %}
LinkedIn OAuth 2.0 Access Token
Your LinkedIn Person URN (from /v2/userinfo API 'sub' field)
